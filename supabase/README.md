# Supabase 데이터 경계

고객 사이트의 인증, 리뷰, 상담 데이터만 Supabase에 연결합니다. `trippick-host/`는 공개 포트폴리오용 정적 데모이므로 Supabase를 불러오지 않습니다.

`migrations/20260823000000_secure_customer_data.sql`은 새 환경용 보안 기준안입니다. 운영 프로젝트에 적용하기 전에 현재 테이블과 정책을 백업하고 차이를 검토해야 합니다. 리뷰는 공개 상태만 익명 조회할 수 있고, 작성·수정·삭제는 로그인한 본인 행으로 제한합니다. 상담 원본 행은 작성자만 직접 읽을 수 있으며, 공개 목록 함수는 비밀글 본문과 답변을 항상 제거합니다.

새 Supabase 프로젝트에서는 Data API 설정에 따라 테이블이 자동 노출되지 않을 수 있습니다. 이 SQL의 명시적 `GRANT`와 RLS 정책을 함께 적용하고, Supabase RLS Tester 또는 역할별 쿼리로 `anon`, `authenticated`, 다른 사용자 계정을 각각 확인하세요.
