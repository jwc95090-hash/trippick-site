# TRIPPICK

초보 캠퍼가 캠핑장 탐색부터 준비와 예약까지 한 흐름으로 이용할 수 있도록 설계한 반응형 캠핑 예약 서비스입니다.

## 주요 기능

- 한국관광공사 공공 캠핑장 데이터 기반 정보 제공
- 캠핑장 검색·필터·지도 보기·찜하기
- 예약·결제·리뷰·마이페이지 흐름
- Google 소셜 로그인
- 캠핑 안내 영상 6편
- 예약·매출·리뷰를 관리하는 호스트센터
- 360px 모바일부터 1920px 화면까지 반응형 지원

## 기술

HTML · CSS · JavaScript · Supabase · 고캠핑 API · Toss Payments · Cloudflare Workers
