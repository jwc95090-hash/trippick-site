예약·정산·상담·리뷰를 한 번에

캠핑장 운영을 관리하는 관리자 콘솔은 예약 흐름, 상담 응답, 수익 정산, 리뷰 운영을 하나의 화면에서 한 번에 확인할 수 있도록 구성되어 있습니다.

01 CORE

예약 관리

예약 상태와 객단가를 한눈에 파악하고, 체크인/입금/취소 흐름을 빠르게 정리할 수 있습니다.

02 CORE

상담 대응

문의 메시지를 목록으로 확인하고, 호스트 답변을 바로 전송해 예약 전환율을 높일 수 있습니다.

03 CORE

정산 대시보드

정산 예정액, 수수료, 환불 내역을 한 번에 확인하고 계좌 정보를 안전하게 관리합니다.

04 CORE

리뷰 운영

리뷰 평점과 사진 리뷰를 파악하고, 빠른 답글 작성으로 재방문율과 신뢰도를 높일 수 있습니다.
