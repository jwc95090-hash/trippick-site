# TRIPPICK 디자인 시스템

이 문서는 트립픽 고객 사이트의 시각 언어와 UX 기준을 정의하는 단일 기준 문서입니다. 기존의 포레스트 리조트 감성은 유지하면서, 캠핑장을 빠르게 찾고 신뢰한 뒤 예약 행동으로 이어지는 흐름을 우선합니다.

## 1. 제품 방향

- **핵심 사용자**: 캠핑 경험이 적거나, 여러 사이트를 비교하는 데 피로를 느끼는 사용자
- **핵심 가치**: 검증된 정보, 쉬운 비교, 초보자를 위한 준비 안내
- **핵심 흐름**: 발견 → 검색 → 비교 → 신뢰 확인 → 예약·문의 → 준비
- **브랜드 인상**: 자연스러움, 차분함, 신뢰감, 절제된 프리미엄
- **콘텐츠 원칙**: 감성 문구보다 사용자가 지금 할 수 있는 행동과 데이터 출처를 먼저 명확히 안내

## 2. 권장 페이지 패턴

### 패턴: Search-led Hero + Social Proof

1. 히어로: 브랜드 메시지, 핵심 CTA, 공공데이터·초보 지원 신뢰 배지
2. 통합 검색: 지역, 날짜, 숙박 스타일, 상세 조건
3. 카테고리: 캠핑·글램핑·카라반 및 테마 탐색
4. 개인화: 취향 매치와 첫 캠핑 준비도
5. 소개·지표: 트립픽의 차별점과 실제 수치
6. 추천 캠핑장: 가격·시설·위치 비교가 쉬운 카드
7. 콘텐츠: 초보 캠핑 가이드
8. 이용 후기: 정량 평점과 이용 맥락을 함께 표시
9. 예약 CTA: 후기 다음에 검색·추천 행동을 반복 제시
10. 신뢰·FAQ·문의: 데이터 출처, 최신성, 정보 한계와 상담 경로

### CTA 원칙

- 첫 화면의 Primary CTA는 `캠핑장 검색하기`
- Secondary CTA는 `1분 취향 추천`
- 후기 다음에 동일 목적의 CTA를 한 번 반복
- 한 화면에서 강조 버튼은 하나만 사용하고 나머지는 보조 스타일로 처리
- 홈 프로모션 쿠폰은 현재 운영 결정에 따라 진입 0.9초 후 자동 노출하며, 닫기와 `오늘 하루 안보기`를 제공

## 3. 스타일 방향

### 스타일: Editorial Nature + Soft Depth

- 넓은 여백과 세리프 제목으로 리조트형 편집 디자인 유지
- 부드러운 그림자와 낮은 대비의 경계선으로 정보 그룹을 구분
- 카드 모서리는 12~22px 범위에서 역할에 따라 일관되게 사용
- 자연 사진과 영상은 콘텐츠 이해를 돕는 범위에서 사용
- 장식보다 검색·비교·예약 상태를 더 강하게 시각화

### 피해야 할 패턴

- 닫기·포커스 이동·노출 제한이 없는 반복 프로모션 모달
- 네온 색상, AI 보라·분홍 그라데이션, 과격한 모션
- 동일 위계의 CTA를 한 화면에 여러 개 배치
- 의미 없는 영문 레이블 남용
- 이모지를 기능 아이콘으로 사용
- 호버에만 의존하는 정보와 조작
- 확인되지 않은 가격·재고·평점을 실제 데이터처럼 표시

## 4. 색상 토큰

| 역할 | 토큰 | 값 | 용도 |
|---|---|---:|---|
| Primary | `--brand` | `#2E4A3A` | 헤더, 핵심 브랜드 영역 |
| Primary Dark | `--forest` | `#132018` | 주요 CTA, 다크 섹션 |
| Primary Deep | `--forest-deep` | `#0C1710` | 푸터, 최고 대비 배경 |
| Secondary | `--secondary` | `#C1663E` | 검색 CTA, 상태 강조 |
| Secondary Dark | `--secondary-deep` | `#9C4A30` | 텍스트형 강조, 활성 상태 |
| Accent | `--brass` | `#AD8A4C` | 포커스 링, 섬세한 포인트 |
| Accent Light | `--brass-light` | `#D8BE87` | 다크 배경 위 포인트 |
| Background | `--paper` | `#FBF8F1` | 기본 페이지 배경 |
| Surface | `--ivory` | `#F6F1E6` | 카드와 보조 표면 |
| Surface Soft | `--ivory-soft` | `#EFE7D4` | 칩, 선택 보조 배경 |
| Text | `--ink` | `#181712` | 본문과 제목 |
| Text Muted | `--text-mute` | `#6E6656` | 보조 설명 |
| Border | `--line` | `#DCD3BC` | 입력창, 카드 경계 |

### 색상 사용 규칙

- Primary CTA에는 `--forest` 또는 `--secondary` 중 하나만 사용
- 골드는 작은 포인트와 포커스 표시에만 사용하고 긴 본문에는 사용하지 않음
- 상태는 색상만으로 전달하지 않고 아이콘·텍스트·레이블을 함께 제공
- 일반 본문 텍스트는 배경 대비 4.5:1 이상을 확보

## 5. 타이포그래피

- **제목**: `Noto Serif KR`, 600~700
- **본문·UI**: `Pretendard`, 400~700
- **기본 본문**: 16px 권장, 최소 14px
- **본문 줄 높이**: 1.6~1.75
- **작은 캡션**: 최소 12px, 핵심 정보에는 사용하지 않음
- 한글 제목에는 `word-break: keep-all`과 적절한 최대 너비를 적용
- 영문 eyebrow는 장식용으로만 사용하고, 의미 있는 한글 제목을 반드시 동반

## 6. 간격과 레이아웃

- 콘텐츠 최대 너비: `1560px`
- 데스크톱 좌우 여백: `40px`
- 모바일 좌우 여백: `20px`
- 섹션 세로 여백: 데스크톱 `80~96px`, 모바일 `56~72px`
- 기본 간격 체계: `4, 8, 12, 16, 24, 32, 40, 56, 72, 96`
- 모바일 우선으로 설계하고 375px에서 가로 스크롤이 없어야 함
- 고정 px 너비보다 `min()`, `max()`, `clamp()`, Grid/Flex를 우선 사용

### 검증 뷰포트

- 375px: 소형 모바일
- 768px: 태블릿
- 1024px: 소형 데스크톱
- 1440px: 일반 데스크톱

## 7. 핵심 컴포넌트

### 히어로

- 화면 높이를 과도하게 점유하지 않고 검색 영역 일부가 첫 화면에 보이도록 구성
- 영상에는 충분한 오버레이를 적용해 텍스트 대비 확보
- 영상 로딩 전 포스터 이미지를 표시하고 `preload="metadata"`로 초기 전송량을 줄이며, 로딩 중에는 포레스트 배경색으로 자연스럽게 대체
- 핵심 CTA 2개와 최대 3개의 신뢰 배지만 표시

### 검색 폼

- 지역·날짜·스타일을 기본 필드로 유지
- 모든 입력에 보이는 `label` 연결
- 오류는 해당 필드 근처와 `aria-live` 영역에 함께 표시
- 제출 버튼의 최소 높이는 48px
- 상세 필터는 점진적으로 펼치되 현재 선택 개수를 표시

### 캠핑장 카드

- 위치 → 이름 → 시설 → 가격·문의 상태 순으로 정보 위계를 고정
- 카드 전체 링크 안에 버튼을 중첩하지 않음
- 찜 버튼은 최소 44×44px, `aria-pressed`와 접근 가능한 이름 제공
- 이미지 공간을 미리 확보하고 가능한 경우 WebP/AVIF와 지연 로딩 사용

### 후기

- 별 문자만 나열하지 않고 `5.0 / 5`처럼 읽을 수 있는 평점으로 표시
- 이용자 맥락(첫 캠핑, 가족, 반려동물)을 함께 표시
- 과장된 수치 대신 검증 가능한 후기 출처와 작성 시점을 우선

### 모달

- 일반 모달은 사용자 행동으로 열고, 홈 쿠폰 모달만 운영 예외로 자동 노출
- `role="dialog"`, `aria-modal="true"`, 제목 연결, ESC 닫기, 포커스 순환·복귀 지원
- 자동 쿠폰은 진입 0.9초 후 한 번 노출하고 `오늘 하루 안보기` 상태를 저장

## 8. 인터랙션과 모션

- 일반 전환: 150~240ms
- 큰 영역 전환: 최대 400ms
- 모션은 상태 변화와 공간적 연결을 설명할 때만 사용
- `width`·`height`보다 `transform`·`opacity` 애니메이션 우선
- `prefers-reduced-motion: reduce`에서 자동 스크롤, 리빌, 영상 기반 움직임을 최소화
- 모든 클릭 가능한 요소에 포인터와 명확한 hover·active·focus-visible 상태 제공

## 9. 접근성 기준

- 본문 대비 4.5:1 이상
- 키보드로 메뉴, 검색, 필터, 카드, FAQ, 모달을 모두 조작 가능
- 터치 대상 최소 44×44px, 인접 조작 간 8px 이상 간격
- 아이콘 전용 버튼에 `aria-label` 제공
- 장식 SVG에는 `aria-hidden="true"` 적용
- 동적 검색 결과, 선택 개수, 준비율은 `aria-live`로 안내
- 자동 재생 영상은 음소거하고 핵심 정보 전달 수단으로 사용하지 않음
- 브라우저 확대를 막지 않음

## 10. 성능 기준

- 첫 화면 영상은 모바일에서 정적 포스터 대체를 고려
- 이미지에 크기 또는 `aspect-ratio`를 지정해 CLS를 0.1 미만으로 유지
- 첫 화면 외 이미지는 `loading="lazy"`
- 동일 jQuery 파일의 중복 제공을 제거하고 신규 기능은 Vanilla JavaScript 유지
- 외부 API 오류 시 빈 화면 대신 데이터 출처와 재시도 방법 표시
- Lighthouse 점검 목표: Accessibility 90+, Best Practices 90+, SEO 90+

## 11. 홈 화면 적용 결정

- 히어로 높이를 줄이고 검색 영역이 첫 화면에 걸쳐 보이도록 조정
- `캠핑장 검색하기`와 `1분 취향 추천` CTA를 함께 제공
- 공공데이터·초보 맞춤·비교 기능 신뢰 배지를 히어로에 추가
- 히어로 영상의 포스터 이미지를 제거해 재생 전 별도 사진이 나타나지 않도록 처리
- 회원가입 쿠폰 모달은 홈 진입 0.9초 후 자동 노출하고 `오늘 하루 안보기` 제공
- 검색 폼의 기본 안내 문구는 제거하되 검증 오류와 검색 결과 안내는 유지

### 캠핑입문가이드 적용 결정

- 에디토리얼 이미지 히어로와 `75초 안전 영상 보기` CTA를 첫 화면에 배치
- 대표 안전 영상 1편은 큰 플레이어와 제작·재생 시간·추천 대상 정보를 함께 표시
- 준비물, 캠핑 매너, 반려동물, 차박, 우천 대응 영상 5편은 반응형 과정형 그리드로 구성
- 모든 영상은 로컬 MP4, 명시적인 한국어 접근성 이름, 키보드 포커스, 초기 음량 28%를 사용
- 375px에서는 1열, 태블릿에서는 2열, 데스크톱에서는 12열 기반 비대칭 그리드로 전환
- 후기 다음에 검색·추천 CTA 반복
- 후기의 별 문자 표현을 읽을 수 있는 정량 평점으로 변경
- 헤더 투명도를 높여 내비게이션 대비 개선

## 12. 배포 전 체크리스트

- [ ] 이모지를 기능 아이콘으로 사용하지 않음
- [ ] 모든 클릭 요소에 pointer, hover, active, focus-visible 상태가 있음
- [ ] 텍스트 명암비 4.5:1 이상
- [ ] 키보드 탐색과 포커스 순서가 자연스러움
- [ ] `prefers-reduced-motion` 지원
- [ ] 44×44px 터치 영역 확보
- [ ] 텍스트·칩·배지가 줄바꿈되어도 잘리거나 겹치지 않음
- [ ] 375px, 768px, 1024px, 1440px 반응형 검증
- [ ] 자동 쿠폰 모달에 닫기, ESC, 포커스 순환, 오늘 하루 안보기 기능이 있음
- [ ] 이미지 공간 확보 및 지연 로딩 적용
- [ ] 검색 오류와 로딩 상태가 화면에 안내됨
- [ ] 가격·재고·평점의 데이터 출처가 명확함
- [ ] 콘솔 오류와 끊어진 링크가 없음
